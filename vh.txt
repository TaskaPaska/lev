IPv4 = 32 bits. Subnet mask decides network vs hosts.

Usable hosts = 2^(host bits) − 2
(network + broadcast are unusable)

Class hints (exam only):
Class C → 192.168.x.0
Class B → 172.16–172.31.x.0

Common masks you must know by heart:
/30 (255.255.255.252) → 2 hosts → router-to-router
/28 (255.255.255.240) → 14 hosts → server VLAN
/25 (255.255.255.128) → 126 hosts → DHCP network
/24 (255.255.255.0) → 254 hosts → normal LAN

Subnet jump = 256 − last mask octet
/30 → +4
/28 → +16
/25 → +128

/30 example:
10.0.0.0 network
10.0.0.1–10.0.0.2 usable
10.0.0.3 broadcast
Next subnet starts at 10.0.0.4

/28 “last subnet” in class C:
192.168.x.240/28
Hosts: .241–.254
Broadcast: .255

Rules to follow in exams:
Router links → /30
“14 hosts” → /28
“126 hosts” → /25
“Last subnet” → highest valid block
Never use network or broadcast IP
